Телефон и браузер вокруг подготовки спортсмена.

Демонстрационный кабинет, короткое приветствие, бег и плавание, учебные карточки и сборка оригинальной сторис 9:16. В личном Telegram-пилоте доступен ручной импорт собственных Garmin FIT/ZIP. Обычный браузер показывает демонстрационный кабинет. Подтверждённому владельцу в Telegram доступен сохранённый экспорт Garmin (CSV или ZIP) через отдельный MCP-модуль на VPS. Автосинхронизация требует отдельного подключения Garmin. Персональный анализ ИИ и генерация изображений этим не включаются. Сохранённый вопрос остаётся в этом браузере.

Книжные основания

Джек Уилмор и Дэвид Костилл — «Физиология спорта и двигательной активности». Владимир Иссурин — «Подготовка спортсменов XXI века: научные основы и построение тренировки».

Карточки кабинета — краткие образовательные пересказы с указанием источника и PDF-страницы. Они не назначают персональную нагрузку. Полные тексты книг здесь не размещаются; поиск работает в отдельном приватном пилоте. Распознанные фрагменты требуют сверки с оригиналом.

На вашем устройстве

Прогресс гида и инструкции сохраняется в этом браузере. У подтверждённого владельца Telegram он сохраняется также на нашем сервере для продолжения на другом устройстве. Полный ZIP Garmin при загрузке обрабатывается в памяти; сохраняются только сводки тренировок и резервная копия прежних сводок.

Сборка оригинальной сторис выполняется локально в браузере. Фото и маршрут не отправляются на сервер или ИИ и не записываются в хранилище сайта. Очистите результат или закройте вкладку, чтобы удалить их из её памяти. Скачанный файл остаётся у вас.

Диагностика осанки на публичном сайте выключена: поля для фотографий недоступны. Учебные схемы доступны без передачи фото.

Вопросы демо-кабинета сохраняются локально: до десяти текстов в этом браузере. При открытии кабинета из Telegram подпись initData передаётся нашему HTTPS API для проверки владельца. Данные Garmin доступны только подтверждённому владельцу; сохраняются показатели тренировок, без GPS, имён и исходных ответов Garmin. Сессия Garmin хранится отдельно на VPS. В обычном браузере личная история не запрашивается. Для размещения используется GitHub Pages: GitHub регистрирует IP посетителей в целях безопасности.
